# Koschei v0.10.12 — `List.scan`

`List<T>.scan(U, fn(U, T) -> U) -> List<U>` performs a deterministic left-to-right prefix accumulation.

- the initial value seeds the accumulator but is not included in the output
- each source element is evaluated exactly once
- each updated accumulator is appended to the result
- source order is preserved and the source list is never mutated
- the reducer must be a local named two-argument function
- reducer input and output contracts are proven by Typed HIR
- raw `Error` reducers are rejected; fallible state must use `Result<T, Error>`
- capability-bearing lists, initial values, reducer signatures, and reducer results are rejected
- interpreter and generated-Go execution use the same fail-closed behavior

```ks
fn add(total: Int, value: Int) -> Int { return total + value }
fn main() {
    println([5, 3, 2, 7].scan(0, add))
}
```

Output:

```text
[5, 8, 10, 17]
```
