# Koschei Universe IDE Contract v1

Universe Mode is an optional spatial development and security interface over the real Koschei compiler/runtime. It is not a replacement language, game engine, or source of authority.

## Two equal developer surfaces

- **Direct Surface** — source editor, diagnostics, build/run/test/package operations.
- **Universe Surface** — the same project represented as navigable Realities, services, packages, conduits, authority boundaries, evidence and runtime state.

Both surfaces operate on the same canonical project identity and backend state. Neither may invent semantics unavailable to the other.

## Spatial mapping

- Project -> home Reality.
- Package -> satellite/module world with provenance and requested-effect manifest.
- Service -> station/city bound to exact network/process authority.
- Database/storage -> persistence realm with exact-object authority.
- Dependency edge -> visible conduit.
- Authority request -> gated portal proposal, never automatic permission.
- Build -> journey through canonical compilation/admission state.
- Test -> isolated simulation Reality.
- Quarantine -> visibly disconnected Reality.
- Fork/rollback -> integrity anomaly rendered from Wanda commitment evidence.
- Root/signing operation -> Vormir-class privileged ceremony backed by real deterministic admission.
- Sentinel -> advisory companion over evidence; never an authority oracle.

## Non-negotiable laws

1. The Universe UI consumes canonical backend state; UI animation is never evidence.
2. Clicking a planet cannot silently grant capability.
3. Every security-relevant interaction produces a reviewable proposal before deterministic admission.
4. Universe Mode must remain usable without exposing secrets or canonical root material to the renderer.
5. Direct Surface and Universe Surface must produce equivalent canonical artifacts for equivalent source and policy.
6. Headless/CI use remains first-class; no build requires a graphical universe.
7. Accessibility and a non-spatial representation are mandatory for every spatial action.

## Package experience

Package discovery may be spatial, but package installation is governed by the Koschei package contract. A package world shows provenance, artifact identity, dependencies, effects, exact targets and budgets. Connecting it to the project creates an admission proposal. Install/import alone grants zero ambient authority.

## Live universe

Runtime state may animate only from authenticated telemetry/evidence. Portal activity maps to real conduit traffic; quarantine maps to actual isolation; authority loss maps to actual revocation/tombstone state. The renderer is read-mostly and must not become a privileged control plane.

## Product objective

Universe Mode should make architecture and security comprehensible at a glance while preserving Koschei's deterministic core. The novelty is not a 3D skin: it is that code structure, dependency provenance, runtime effects and authority boundaries become one navigable model.
