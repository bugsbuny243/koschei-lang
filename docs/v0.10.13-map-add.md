# Koschei v0.10.13 — `Map.add`

`Map<String, N>.add(String, N) -> Map<String, N>` performs immutable numeric accumulation for `Int` and `Float` maps.

- a missing key is inserted with the supplied delta
- an existing key is replaced by `existing + delta`
- the source map is never mutated
- existing key order is preserved and a new key is appended once
- `Int` addition keeps the signed 64-bit overflow contract (`KS3501`)
- `Int` and `Float` cannot be mixed silently
- non-numeric maps are rejected by Typed HIR
- capability-bearing keys or values are rejected before ordinary type diagnostics
- interpreter and generated-Go execution share the same fail-closed behavior

```ks
struct Purchase { customer: String, amount: Int }
fn main() {
    let purchases = [Purchase { customer: "Ada", amount: 5 }, Purchase { customer: "Ada", amount: 3 }]
    let mut totals: Map<String, Int> = {}
    for purchase in purchases { totals = totals.add(purchase.customer, purchase.amount) }
    println(totals.get("Ada") or 0)
}
```

Output:

```text
8
```
