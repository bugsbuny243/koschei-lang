# Koschei Lang — standalone programming language charter v1

Koschei Lang is an independent commercial programming language and developer ecosystem. It is sold separately from Koschei Web3 Hub and Koschei Sentinel.

## Product mission

Build a world-class general-purpose programming language with cybersecurity principles embedded into the language, compiler, runtime, capability model, standard library and developer tooling.

"World-class" is a development target. Comparative claims against Rust, Go, C++, Python or other languages require reproducible benchmarks, defined threat models and executed compatibility/performance/security tests.

## Product identity

Koschei Lang owns and evolves:

- `.ks` language syntax and semantics;
- compiler and native toolchain;
- runtime and execution model;
- capability-secure authority model;
- standard library and package/library ecosystem;
- Matrix/policy/proof layers where defined by the Lang architecture;
- identity and permission primitives owned by the language;
- debugging, testing, package, build and developer tooling;
- release trust, compatibility and language governance.

Web3 and AI integrations are applications of the language, not the identity of the language.

## Security direction

The language should minimize ambient authority, make privileged operations explicit, support strong isolation and verification boundaries and make insecure behavior harder to express or easier to detect. Any superiority claim must be backed by measurable evidence.

## Interoperability

Koschei Lang may integrate with Koschei Sentinel, Koschei Web3 Hub or external systems through explicit libraries, SDKs, adapters and versioned contracts.

Interoperability does not make those products runtime dependencies and does not merge their billing or entitlements.

## Commercial rule

Koschei Lang has its own pricing, licensing, entitlement, distribution and customer-access policy. Buying Web3 or Sentinel does not automatically grant Lang access, and buying Lang does not automatically grant the other products.
