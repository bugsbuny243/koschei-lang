## 2026-09-18 fresh intake

### Agent Registry Protocol reinforces protocol-neutral identity/evidence interfaces
`draft-sankarshan-agent-registry-protocol-00`, published 2026-09-17, proposes HTTP/JSON agent registry objects for operator/deployment relationships, bounded authority, lifecycle state and evidence. It is an Individual Submission Internet-Draft with intended Standards Track status, not an adopted standard.

**Lang opportunity:** keep identity/authority/evidence interfaces protocol-neutral. A registry lookup result should remain external/untrusted evidence until application/runtime policy validates freshness, provenance and scope.

**Threat:** hard-coding a draft registry protocol into language semantics would create premature coupling and could incorrectly equate discoverability with authority.

**Design candidate:** library/runtime interfaces can distinguish `DiscoveredAgent`, `Evidence<T>`, `VerifiedPrincipal`, `Authority<Scope>` and fresh effect authorization without adding new syntax. Benchmark first.

### Plugin4Shell strengthens artifact-identity and provenance requirements
The Sep 17 AIR Security disclosure reports a supply-chain class where a reviewed/pinned plugin identity could diverge from the code materialized by an agent client. The architecture lesson is independent of the specific exploit mechanics.

**Lang opportunity:** evaluate content-addressed module/package provenance and runtime/build evidence that binds requested dependency identity to resolved artifact identity.

**Threat:** cryptographic metadata is useless if the implementation does not verify the final artifact/effect it is supposed to bind.

**Competitor gap:** a security-first language can make provenance verification easier to express and audit, but should not promise safety solely from pinning or package metadata.

**Design review candidate:** `requested artifact -> resolved artifact -> verified digest/provenance -> loaded module` continuity as a package/runtime invariant. Keep this at defensive architecture level; no exploit implementation is required.
