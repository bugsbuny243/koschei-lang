## Existing directions

## 2026-09-22 fresh intake

### Runtime revocation must be separate from identity
Okta's 2026-09-22 agent-security direction emphasizes first-class non-human agent identities, runtime enforcement and kill-switch controls. Aembit announced Cross App Access support. XAA is an open vendor protocol/ecosystem, not an IETF/W3C standard.

**Lang opportunity:** strengthen the distinction between identity evidence, scoped capability, runtime policy state, revocation state and effect authorization.

**Threat:** a language/runtime that treats successful authentication as durable authority cannot cleanly represent policy changes during long-running autonomous work.

**Design review:** protocol-neutral revocable capability/authority handles and freshness witnesses at effect boundaries; no XAA-specific syntax.

### MCP security-context delivery reinforces typed evidence boundaries
Wiz announced MCP-powered integrations for agents to retrieve live security context. This is deployment/adoption evidence for agent-tool interoperability, not a reason to hard-code MCP into language semantics.

**Lang opportunity:** external security findings should enter as evidence/context with source, freshness and trust metadata rather than as implicitly trusted values.

**Design review:** `Evidence<T>`-style library/runtime contracts that preserve provenance/freshness across tool boundaries.

### PQ plus communication containment reinforces multi-dimensional security policy
Aviatrix announced crypto-agile/post-quantum protection combined with workload communication governance on 2026-09-22.

**Lang opportunity:** keep cryptographic policy separate from reachability/effect policy. Strong encryption does not imply a safe capability graph.

**Design review:** ensure crypto-provider policy and capability/network-effect policy can evolve independently.

## Standards reality
No accepted IETF/W3C Web4/Web5/Web6/Web7/Web8 generation standard was identified in the last 24 hours. XAA is vendor/open-ecosystem work; MCP is an open application protocol with broad adoption. Do not encode Web-generation branding or transient vendor wire formats into language semantics.
