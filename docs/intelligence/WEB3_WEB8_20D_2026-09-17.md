## 2026-09-24 fresh intake

### Quantumnet reinforces component-level crypto agility
Tezos launched experimental Quantumnet on 2026-09-24. It combines ML-DSA-44 account signatures with changes/experiments across other L1 cryptographic responsibilities rather than treating PQ migration as a single signature swap.

**Opportunity:** Lang's crypto abstraction should allow different security domains/components to migrate independently under explicit policy.
**Threat:** a single global “crypto mode” would poorly model mixed classical/PQ systems and staged migration.
**Design review:** provider/capability metadata should express algorithm family, domain of use, migration state and compatibility without hard-wiring Tezos-specific semantics.

### ETSI QRNG guidance reinforces typed entropy provenance
ETSI TR 104 171, announced 2026-09-24, emphasizes entropy-source validation, extraction, runtime monitoring and provenance rather than trusting a “quantum” source label.

**Opportunity:** security-sensitive randomness APIs can distinguish raw/untrusted entropy observations from conditioned/verified randomness and preserve provider provenance.
**Threat:** treating every byte source implementing a random interface as semantically equivalent hides critical trust assumptions.
**Design review:** explore library/runtime contracts for `EntropySource -> ExtractedRandomness -> KeyMaterial` with evidence/provider metadata; no new syntax is mandated.

### AINS reinforces discovery/verification separation
`draft-vandemeent-ains-discovery-02` proposes rich agent discovery records with identity/capability/endpoint/evidence references.

**Opportunity:** existing `Evidence<T>` / scoped-authority direction should make discovery metadata explicitly non-authoritative until independently verified.
**Threat:** coupling language semantics to a transient Internet-Draft or treating discovery records as capabilities.
**Design review:** protocol-neutral resolver interfaces should return claims/evidence references separately from verified principals and effect authority.

## Standards reality
No accepted Web4/Web5/Web6/Web7/Web8 generation standard was identified. AINS is an Informational Internet-Draft; ETSI TR 104 171 is technical guidance; Quantumnet is an experimental testnet. Do not encode these labels or transient wire formats into language semantics.
