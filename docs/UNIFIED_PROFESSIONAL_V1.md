# Koschei Lang — Unified Professional v1

Status: commercial integration contract

Koschei Lang remains an independent capability-secure programming language and developer ecosystem. It is included commercially in the unified **Koschei Professional** plan together with Koschei Web3 Hub, ARVIS and Koschei Sentinel.

## What Professional inclusion means

An active Professional entitlement may authorize licensed Koschei Lang customer tooling/artifacts when an approved distribution channel and the corresponding Lang release gates are available.

Professional inclusion does **not** make Web3 or Sentinel authoritative over the language. Koschei Lang remains the source of truth for:

- `.ks` language semantics;
- compiler and runtime behavior;
- capability/authority rules;
- standard library behavior;
- Matrix policy/proof internals;
- release trust, artifact integrity and compatibility;
- editor and developer-toolchain behavior.

Web3 integration must use explicit Koschei Fabric contracts/adapters. Lang internals are not copied into Web3 and Web3 does not become a required compiler/runtime dependency.

## One official Koschei token

There is one official ecosystem token: **KOSC**, Solana mainnet mint `7X9V77axASFAV8hKqqn2EfyAz4Qz3tceN8iikfukLqy1`.

There is no separate Koschei Lang token. KOSC may act as an alternate verified settlement path into the same Professional entitlement, but token ownership/payment cannot alter compiler semantics, capability permissions, Matrix policy, proof results, release trust or artifact acceptance.

## Distribution boundary

The current repository does not claim that a public unrestricted Lang binary/package channel exists. A Professional entitlement is therefore not itself proof that a particular Lang artifact has been published or approved.

Customer-facing download/install surfaces must be enabled only after a signed/licensed artifact channel exists and existing Lang integrity/release checks pass. Until then, Professional can truthfully advertise Lang as included in the commercial package while runtime/artifact availability remains separately reported.

## Sentinel relationship

Lang and Sentinel may be included under the same Professional commercial umbrella, but Sentinel model output never gains compiler or language authority. Their implementations, release gates and security evidence remain independent.
