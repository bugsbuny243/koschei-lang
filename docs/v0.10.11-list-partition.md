# Koschei v0.10.11 — `List.partition`

`List<T>.partition(fn(T) -> Bool) -> List<List<T>>` divides a list into two fresh lists while preserving source order.

- index 0 contains values for which the predicate returns `true`
- index 1 contains values for which the predicate returns `false`
- the source list is never mutated
- the predicate must be a local named one-argument function returning `Bool`
- capability-bearing inputs and callback signatures are rejected
- interpreter and generated-Go execution share the same fail-closed behavior

```ks
fn negative(value: Int) -> Bool { return value < 0 }
fn main() {
    let groups = [-3, 2, 0, 5, -1].partition(negative)
    for group in groups { println(group) }
}
```
