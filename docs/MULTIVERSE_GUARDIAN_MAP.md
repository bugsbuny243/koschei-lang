# Koschei Multiverse Guardian Map v1

The character names are internal architecture mnemonics. Every guardian must map to a concrete, testable security primitive; no guardian exists only for theme.

| Mnemonic | Technical responsibility | Authority rule |
|---|---|---|
| Neo / Sentinel | evidence interpretation, anomaly reasoning, restriction/quarantine recommendation | never grants authority; never overrides deterministic rejection |
| Wanda | reality commitment chain, fork and rollback detection | cannot rewrite accepted history |
| Loki | non-authoritative adaptive deception surfaces and tripwire evidence | decoys contain no canonical secret or executable authority |
| Doctor Strange | bounded future-path simulation before effect admission | simulation cannot execute external effects or mint authority |
| Hela | irreversible authority death / resurrection prevention | dead authority cannot reappear through replay, fork or stale epoch |
| Captain Marvel | blast-radius absorption and propagation budget | containment may remove/restrict power, never widen it |
| Vormir | root-reality admission through explicit sacrifice | privileged admission requires actual attenuation and fresh epoch |
| Gauntlet | convergence of six security domains into deterministic admission | all mandatory deterministic domains must agree |
| Matrix Fabric | evidence/message transit among isolated realities | connectivity never implies authority |

## Architectural rule

New fictional mnemonics are accepted only when they introduce a distinct security invariant not already represented above. Duplicate characters do not create duplicate subsystems.

## Execution order

A useful high-risk path is:

`Wanda reality proof -> Strange future-path proof -> Gauntlet admission -> effect -> Captain Marvel propagation budget -> evidence -> Sentinel interpretation`

Revocation enters Hela. Root escalation enters Vormir. Suspicious reconnaissance may be redirected only into Loki's non-authoritative surfaces.

This ordering is descriptive, not ambient permission. Each primitive must independently fail closed.
