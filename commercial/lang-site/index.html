BUILT FOR CONTROL

Know what your software can do.

Language-level protections you can test and inspect, without claiming every threat outside the Koschei toolchain is solved.

◇

Explicit capabilities

Disk, network, environment and process operations require capabilities explicitly passed into Koschei code.

⊘

Compile-time rejection

ks check rejects the bundled unauthorized-import example with diagnostic KS2401 before running it.

⌁

Auditable reach

ks caps reports the program's reachable capabilities. ks caps --deny net can fail CI when network authority appears.

⌘

Run and compile

ks run uses the checked interpreter. ks build compiles native applications through the present Go-based adapter.

▦

Core Library

Typed collections, text helpers and SHA3-256 digest support, with growing libraries authored in Koschei source.

▣

Practical examples

Includes secretscan, directory-integrity examples, a VS Code extension and bilingual reference guides.

FAQ

Before you start.

Does the $49 license expire?

No. You can use acquired versions indefinitely; versions released within 12 months of purchase are included.

Is Go required?

Python 3.12+ is required for installation and the interpreter. Go 1.24+ is required when you use ks build.

Is this a Web3-only language?

No. Koschei Lang is an independent general-purpose language. Web3 and AI integrations are separate applications, not the language's required runtime.

Can I redistribute the compiler?

Not without separate permission. Programs you author and the binaries produced by ks build belong to you, subject to the LICENSE. The Koschei toolchain itself is proprietary.
