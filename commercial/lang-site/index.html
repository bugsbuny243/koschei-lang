BUILT FOR CONTROL

Know what your software can do.

Language-level protections you can test and inspect, without claiming every threat outside the Koschei toolchain is solved.

◇

Explicit capabilities

Disk, network, environment and process operations require capabilities explicitly passed into Koschei code.

⊘

Compile-time rejection

ks check rejects the bundled unauthorized-import example with diagnostic KS2401 before running it.

⌁

Auditable reach

ks caps reports the program's reachable capabilities. ks caps --deny net can fail CI when network authority appears.

⌘

Run and compile

ks run uses the checked interpreter. ks build compiles native applications through the present Go-based adapter.

▦

Core Library

What this product is — and isn't

Koschei Lang 0.24.0 is pre-1.0 proprietary developer software. The native compiler uses an existing Go adapter; it is not a fully self-hosted or independently certified banking runtime.

It does not automatically make third-party operating-system executables safe or prevent stolen credentials, compromised endpoints, wallet signing abuses or all supply-chain attacks.

Personal noncommercial use is free under the license; business evaluation is permitted for up to 30 days. See the included LICENSE for binding terms.

BEYOND 0.14.0 · ENGINEERING ROADMAP

A language that keeps evolving.

Milestones below are technical priorities, not announced releases or promised dates. Work is accepted only after security checks and interpreter/native parity.

RELEASED · 0.14.0

Current foundation

Explicit capabilities, lambdas without capture, a faster checked interpreter and Go-based native builds. Some features, including generic structs, remain interpreter-only.

PROPOSED · NEXT

Runtime parity

Close native/interpreter gaps in generic structs, structured data and database access. Prove equivalent output, types, errors and capability checks before calling a feature complete.

PLANNED · HARDENING

Bounded core libraries

Enforce consistent byte, time, and resource budgets for JSON, output, disk, network and secure backend services. Keep incomplete capabilities marked as reserved.

TARGET · 1.0 GATES

Production confidence

Reproducible self-hosted compiler path, signed dependency ecosystem, multi-platform targets, compatibility promises, fuzzing and independent security review. Not yet achieved.

Version policy: 0.24.0 remains the current published version until a separately validated release is cut. Candidate numbers such as 0.25.0 are proposals, not shipping promises. The $49 language license includes versions released within 12 months of purchase.

FAQ

Before you start.

Does the $49 license expire?

No. You can use acquired versions indefinitely; versions released within 12 months of purchase are included.

Is Go required?

Python 3.12+ is required for installation and the interpreter. Go 1.24+ is required when you use ks build.

Is this a Web3-only language?

No. Koschei Lang is an independent general-purpose language. Web3 and AI integrations are separate applications, not the language's required runtime.

Can I redistribute the compiler?

Not without separate permission. Programs you author and the binaries produced by ks build belong to you, subject to the LICENSE. The Koschei toolchain itself is proprietary.
