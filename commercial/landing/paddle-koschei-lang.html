Koschei Lang · Paddle production channel

Make authority explicit before code gets the chance to use it.

Koschei Lang is a pre-1.0 proprietary developer language/toolchain focused on capability-first authority. For covered language paths, code that requests disk, network, environment, or process effects without the required capability is rejected by the compiler.

Checkout is disabled until the live Paddle client token and price ID are injected by deployment configuration.

What you receive

  • Source-free Koschei Lang command-line executable for the purchased platform.
  • Signed production manifest binding the exact executable SHA-256 and size.
  • Measured platform/libc/dynamic dependency requirements.
  • Independent release-key/fingerprint verification instructions.
  • ks new, ks check, ks run, ks caps, formatter and LSP command surface.

Security boundary

PROTECTS AGAINST: covered unauthorized effects that are absent from the checked capability scope, plus tampering of a production download when the independent release key is used.

DOES NOT PROTECT: host/kernel compromise, malicious build/signing infrastructure, arbitrary foreign/native escape paths, or every software vulnerability. Full physical runtime custody is not claimed complete.

ASSUMPTIONS: the purchased artifact is verified against the independently published key/fingerprint and the documented runtime requirements are satisfied.

FAILURE MODE: unsupported strict native execution fails closed rather than silently using the legacy ambient-authority backend.

Current limits

Pre-1.0. Native ks build currently requires a compatible Go toolchain for supported strict MIR-Go programs. Stdlib and platform coverage are incomplete. Exact platform support and runtime dependencies are stated on the purchase/download page.
